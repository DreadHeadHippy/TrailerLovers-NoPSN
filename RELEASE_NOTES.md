# TrailerLovers-NoPSN Release

**Modified Playnite theme based on the original TrailerLovers theme by blooderscrew**

## 🎮 Installation

### Quick Install (Recommended)
1. Download the `.pthm` file below
2. Double-click the file to install automatically in Playnite
3. Go to Playnite Settings → General → Theme
4. Select "TrailerLovers-NoPSN" from the dropdown
5. Apply and enjoy!

### Manual Install
1. Extract the `.pthm` file (it's just a ZIP)
2. Copy contents to `%AppData%\Playnite\Themes\Fullscreen\TrailerLovers-NoPSN\`
3. Restart Playnite and select the theme

## 📋 Requirements
- **Playnite**: Version 9.0 or later
- **Display**: Optimized for 1920x1080 and 3440x1440 (21:9 ultrawide)

## ⚙️ Recommended Settings
- **View Type**: Grid with horizontal scrolling enabled  
- **Columns**: 10
- **Element Spacing**: 37 pixels

## 🔌 Recommended Extensions
For the best experience, install these extensions:
- **ExtraMetadataLoader** - Enhanced game metadata
- **ExtraMetadataLoader Fullscreen Helper** - Fullscreen integration  
- **How Long To Beat** - Game completion times
- **SuccessStory** - Achievement tracking
- **Splash Screen** (optional) - Custom loading screens
- **PlayniteSound** (optional) - Audio enhancements
