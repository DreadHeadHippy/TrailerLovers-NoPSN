# Installation Guide

This guide provides detailed instructions for installing the TrailerLovers-Personal theme for Playnite.

## System Requirements

- **Playnite**: Version 9.0 or later
- **Operating System**: Windows 10/11
- **Display Resolution**: Optimized for 1920x1080 and 3440x1440 (21:9)

## Installation Methods

### Method 1: Automatic Installation (Recommended)

1. **Download the Theme Package**
   - Go to the [Releases page](https://github.com/DreadHeadHippy/TrailerLovers-NoPSN/releases)
   - Download the latest `.pthm` file

2. **Install the Theme**
   - Double-click the downloaded `.pthm` file
   - Playnite will automatically install the theme
   - Restart Playnite if prompted

3. **Activate the Theme**
   - Open Playnite
   - Press `F4` to access Fullscreen mode
   - Go to Settings (gear icon)
   - Navigate to **General** → **Theme**
   - Select "TrailerLovers-NoPSN" from the dropdown
   - Click **Apply**

### Method 2: Manual Installation

1. **Download and Extract**
   - Download the source code from the [Releases page](https://github.com/DreadHeadHippy/TrailerLovers-NoPSN/releases)
   - Extract the ZIP file to a temporary location

2. **Copy Theme Files**
   - Open the Playnite themes directory:
     ```
     %AppData%\Playnite\Themes\Fullscreen\
     ```
   - Create a new folder named `TrailerLovers-NoPSN`
   - Copy all extracted files into this folder

3. **Restart and Activate**
   - Restart Playnite completely
   - Follow steps 3-6 from Method 1

## Recommended Configuration

After installation, configure these settings for the best experience:

### Display Settings
1. Open Playnite Settings (`F4` then gear icon)
2. Go to **Fullscreen** → **General**
3. Set the following:
   - **View**: Grid
   - **Horizontal scrolling**: ✓ Enabled
   - **Columns**: 10
   - **Element spacing**: 37 pixels

### Required Extensions

Install these extensions for full functionality:

#### Essential Extensions
- **ExtraMetadataLoader** ([Download](https://playnite.link/addons.html#ExtraMetadataLoader))
- **ExtraMetadataLoader Fullscreen Helper**
- **How Long To Beat**
- **SuccessStory**

#### Optional Extensions
- **Splash Screen** (for custom loading screens)
- **PlayniteSound** (for audio enhancements)

**To install extensions:**
1. In Playnite, go to **Settings** → **Add-ons**
2. Click the **Browse** tab
3. Search for each extension by name
4. Click **Install** for each extension
5. Restart Playnite

## Troubleshooting

### Theme Not Appearing
- Ensure Playnite is completely closed before installation
- Check that files are in the correct directory: `%AppData%\Playnite\Themes\Fullscreen\TrailerLovers-NoPSN\`
- Verify that `theme.yaml` exists in the theme folder

### Display Issues
- Check your display resolution settings
- Ensure you're using Fullscreen mode (`F4`)
- Try adjusting the grid settings if elements appear too small/large

### Extension Problems
- Verify all required extensions are installed and enabled
- Check extension compatibility with your Playnite version
- Update extensions to their latest versions

## Updating the Theme

1. Download the latest version from [Releases](https://github.com/DreadHeadHippy/TrailerLovers-NoPSN/releases)
2. Follow the installation steps above
3. Existing settings will be preserved

## Getting Help

If you encounter issues:

1. Check the [Issues page](https://github.com/DreadHeadHippy/TrailerLovers-NoPSN/issues) for known problems
2. Create a new issue with:
   - Your Playnite version
   - Your Windows version
   - Screenshots of the problem
   - Steps to reproduce the issue

## Uninstallation

To remove the theme:

1. Open the themes directory: `%AppData%\Playnite\Themes\Fullscreen\`
2. Delete the `TrailerLovers-NoPSN` folder
3. Restart Playnite
4. Select a different theme in Settings
