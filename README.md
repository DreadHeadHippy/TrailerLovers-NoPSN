- **Comprehensive Game Information**: Displays all essential game metadata beautifully

## 🚀 Quick Install

### Option 1: Direct Download (Recommended)
1. Go to the [Releases](https://github.com/DreadHeadHippy/TrailerLovers-NoPSN/releases) page
2. Download the latest `.pthm` file
3. Double-click the file to install automatically in Playnite

### Option 2: Manual Install
1. Download and extract the theme files
2. Copy to your Playnite themes folder: `%AppData%\Playnite\Themes\Fullscreen\`
3. Restart Playnite and select the theme

## ⚙️ Recommended Settings

For the best experience, configure Playnite with these settings:

- **View Type**: Grid view with horizontal scrolling enabled
- **Grid Columns**: 10 columns
- **Spacing**: 37 pixels between elements

## 🔌 Required Extensions

Install these extensions for the complete experience:

### Essential Extensions
- **ExtraMetadataLoader** - Enhanced game metadata
- **ExtraMetadataLoader Fullscreen Helper** - Fullscreen integration
- **How Long To Beat** - Game completion times
- **SuccessStory** - Achievement tracking

### Optional Extensions
- **Splash Screen** - Custom loading screens
- **PlayniteSound** - Audio enhancements

**Installation:** Go to Playnite Settings → Add-ons → Browse tab to install extensions.
